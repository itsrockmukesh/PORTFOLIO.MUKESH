Background & Story

The Engineering Journey

AWS Builder Center Future Builders Connect • AWS Student Portfolio Hackathon

"I am a first-year Computer Science Engineering student at Mirai School of Technology, obsessed with writing clean, structured code and understanding systems from the ground up."

My engineering journey began with the building blocks of the web—crafting semantic HTML and responsive CSS layouts. Rather than jumping straight into heavy frameworks, I chose to understand foundational mechanics: how the browser parses the DOM, renders stylesheets, and creates responsive visual hierarchies.

In parallel, I am tackling Data Structures and Algorithms using C++, developing analytical problem-solving intuition and deep respect for algorithmic efficiency, time complexity, and memory management.

To connect theoretical computer science with real-world infrastructure, I've earned 5 Google Cloud Skill Badges spanning Compute Engine, Cloud IAM security, data pipelines, and Generative AI prototyping in Google AI Studio. This website was built for the AWS Student Portfolio Hackathon and architected for continuous deployment on AWS Amplify.
